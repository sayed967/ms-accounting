# أ. محمد سيد للاستشارات المحاسبية

نظام إدارة مكتب الاستشارات المحاسبية.

## البنية
- Supabase: قاعدة البيانات والمصادقة والصلاحيات.
- Google Drive: المستندات فقط، ويتم حفظ روابط الملفات داخل Supabase.
- Vercel: نشر الواجهة.

## الوحدات
- العملاء
- الشركات التابعة للعميل
- شركات صناعية / استثمارية
- الإقرارات الضريبية
- المستندات
- المهام والمواعيد
- التحصيل والمديونيات
- التنبيهات
- المستخدمون والصلاحيات
- سجل التعديلات

## التشغيل
الواجهة الحالية Static HTML وتتصل مباشرة بـ Supabase باستخدام Publishable Key فقط. لا يوجد Service Role Key في المتصفح.

## النشر
اربط هذا الـRepo بمشروع Vercel `ms-accounting` واجعل الفرع `main` هو Production Branch.
